SOURAV KUMAR RANJAN — STANDALONE PORTFOLIO

Files:
- index.html: page content
- styles.css: complete design and responsive styling
- script.js: mobile navigation and automatic footer year
- assets/: ribbon, technology logos, project placeholders, and résumé

How to use:
1. Keep all files and the assets folder together.
2. Open index.html in a browser.
3. To publish, upload the entire folder to Netlify, GitHub Pages, or any static host.
4. Replace the three project JPG files in assets/ while keeping the same filenames, or update their paths in index.html.
